概念

卡方分布與檢定

卡方分布是一種只取正值且右偏的分布，其形狀由自由度決定。卡方檢定比較觀察次數與期望次數的差異，評估差異是否足夠大到拒絕零假設，常用於類別資料的獨立性或適合度檢定。

The chi‑square distribution is a right‑skewed distribution that only takes positive values and whose shape is determined by the degrees of freedom. A chi‑square test compares observed and expected counts to see if the differences are large enough to reject the null hypothesis and is commonly used for independence or goodness‑of‑fit tests with categorical data.

優缺點與限制

卡方檢定的利弊

卡方檢定是一種非參數方法，優點是計算容易，適用於類別或順序資料，且不要求母體常態或方差齊性；它可處理兩組或多組分類資料，並提供各分類對差異貢獻的詳細訊息。這種檢定廣泛用於獨立性和適合度檢定，可在不符合參數假設時替代 t 或 F 檢定。缺點包括需要足夠大的樣本，通常建議每格期望值至少 5；當樣本過小或表格格數過多時檢定不可靠。資料必須是互斥的計數，每個觀察只能落在一個類別，且觀察彼此獨立。卡方檢定僅提供是否存在關聯的顯著性，無法衡量關聯強度，且對於配對樣本或比例極端失衡時不適合使用。

The chi‑square test is a non‑parametric method. Its advantages include ease of computation, applicability to nominal or ordinal data, and no requirement of normality or equal variances. It can handle two or more categorical groups and provides detailed information about which cells contribute to differences. It is widely used for independence and goodness‑of‑fit tests and serves as an alternative to t or F tests when parametric assumptions are violated. Limitations include the need for a sufficiently large sample; each expected count should typically be at least 5. With small samples or many categories, results may be unreliable. Data must be mutually exclusive counts with each observation falling into only one category, and observations must be independent. The chi‑square test only indicates whether an association exists and does not measure its strength, and it is not suitable for paired samples or highly unbalanced tables.

決策指引與範例

何時使用卡方檢定

在選擇卡方檢定時，首先確認變數為類別或已分組的順序資料。若欲檢驗兩分類變數的獨立性或某變數的分布是否符合理論比例，可使用卡方檢定。應確保每一樣本單位僅屬於一個類別且樣本來自隨機抽樣；若資料是配對或重複測量則不適用，應改用 McNemar 檢定或其他方法。當任何格子期望值低於 5 或總樣本量少於 50 時，建議改用 Fisher 精確檢定或合併類別以增加期望值。此外，卡方檢定只能判斷是否有顯著關聯，若要衡量關聯強度可另計算 Cramer’s V 或 Phi 係數。範例：研究者想知道吸菸習慣與是否罹患某疾病是否有關，收集 120 名受試者後得到 2×2 表格；使用卡方檢定計算 χ² 值和 p 值，若 p < 0.05，則表示吸菸與疾病有統計上的關聯。

To decide when to use a chi‑square test, confirm that your variables are categorical or binned ordinal. Use the test to examine whether two categorical variables are independent or whether an observed distribution matches a theoretical one. Ensure that each subject belongs to only one category and that observations are from a random sample; for paired or repeated measures data, use the McNemar test or other alternatives. If any expected count is less than 5 or the total sample size is below about 50, consider Fisher’s exact test or combining categories to increase expected counts. Remember that the chi‑square test only indicates whether an association exists; to quantify the strength of association you can compute Cramer’s V or the Phi coefficient. Example: a researcher wants to assess whether smoking status is associated with a disease. After collecting data from 120 individuals, they create a 2×2 contingency table. A chi‑square test yields a χ² statistic and p‑value; if p < 0.05, smoking and disease occurrence are considered statistically associated.

程式範例

使用 R 與 Python 進行卡方檢定

以下程式碼示範如何在 R 和 Python 中建立 2×2 交叉表格、計算卡方統計量與期望值。若表格期望次數過小，R 會建議使用 fisher.test()，Python 可使用 stats.fisher_exact()。你可以切換標籤查看不同語言，並點擊複製按鈕取得程式碼。

The following code shows how to construct a 2×2 contingency table in R and Python, compute the chi‑square statistic and expected counts. If expected counts are too small, R suggests using fisher.test() and Python has stats.fisher_exact(). Use the tabs to switch languages and click the copy button to copy the code.

# 產生 2×2 交叉表格
tab <- matrix(c(20, 30, 15, 35), nrow = 2, byrow = TRUE)
colnames(tab) <- c("Yes", "No")
rownames(tab) <- c("Group1", "Group2")

# 執行卡方檢定（不使用連續性校正）
  chisq.test(tab, correct = FALSE)

# 取得期望值與統計量
  chi_res <- chisq.test(tab, correct = FALSE)
  chi_res$expected
  chi_res$statistic
# Import packages
import numpy as np
from scipy import stats

# Create 2×2 contingency table
obs = np.array([[20, 30], [15, 35]])

# Chi‑square test without Yates' correction
  chi2, p_val, dof, expected = stats.chi2_contingency(obs, correction=False)
  expected
  chi2

# If expected counts are small, use Fisher’s exact test
  oddsratio, p_exact = stats.fisher_exact(obs)
  p_exact
