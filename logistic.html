Step 9

邏輯斯迴歸

適用於二元或分類反應的回歸模型，利用 logistic 函數將預測機率限制在 0 到 1 之間。

A regression model for binary or categorical responses that uses the logistic function to constrain predicted probabilities between 0 and 1.

概念

邏輯斯模型

在邏輯斯迴歸中，對數機率（logit）與解釋變數線性相關：log(p/(1−p)) = β₀ + β₁ x。將其轉換回機率形式，可得 logistic 函數：p = 1/(1 + e−(β₀ + β₁ x))。此模型常用於預測二元結局。

In logistic regression the log odds are linearly related to the predictor: log(p/(1−p)) = β₀ + β₁ x. Converting this back to a probability yields the logistic function p = 1/(1 + e−(β₀ + β₁ x)). This model is often used to predict binary outcomes.

優缺點與限制

優勢與局限

下列列出使用邏輯斯迴歸時常見的優點與缺點。邏輯斯迴歸是一種容易實作且易於解釋的模型，但仍有假設與限制需要留意。

Below are common advantages and drawbacks when using logistic regression. While logistic regression is straightforward to implement and interpret, there are assumptions and limitations to keep in mind.

優點

  • 模型簡單且訓練效率高，參數估計容易收斂。
  • 輸出係數可直接說明自變數對對數比值 (logit) 的影響方向與大小，易於解釋。
  • 對自變數分布的假設較少，可處理連續與類別型變數。
  • 可以擴展到多分類（多元邏輯斯迴歸），應用廣泛。
  • Simple model with efficient training; parameter estimation converges quickly.
  • Coefficients directly indicate the direction and magnitude of predictors’ effects on the log odds, making results interpretable.
  • Requires few assumptions about the distribution of predictors and handles both continuous and categorical variables.
  • Extends to multiclass problems (multinomial logistic regression) and is widely used across fields.

缺點與限制

  • 樣本量需多於自變數數量，否則容易過度擬合。
  • 假設解釋變數與 logit 之間呈線性關係，只能建立線性決策邊界，不適合複雜非線性模式。
  • 對多重共線性敏感，若自變數高度相關會影響估計結果。
  • 當資料在特徵空間上線性不可分時，模型表現較差，且高維特徵容易過度擬合。
  • Requires that the number of observations exceed the number of predictors; otherwise, it may overfit.
  • Assumes a linear relationship between predictors and the log odds, so it creates only linear decision boundaries and does not capture complex nonlinear patterns.
  • Sensitive to multicollinearity—highly correlated predictors can distort coefficient estimates.
  • Performs poorly when classes are not linearly separable and can overfit high‑dimensional data.
決策與範例

何時使用邏輯斯迴歸

邏輯斯迴歸適合建模二元或分類結果，以下為一些應用建議：

Logistic regression is appropriate for modeling binary or categorical outcomes. Consider the following guidance:

  • 確保觀察值相互獨立，自變數彼此獨立且樣本數量足夠。
  • 連續型自變數與 logit 之間應近似線性；若顯著非線性可考慮特徵轉換或使用其他模型。
  • 避免高度相關的自變數，必要時可採用降維或刪除共線性變數。
  • 依據資料類型選擇模型：二元結果用二元邏輯斯迴歸，多分類結果可用多元邏輯斯迴歸。
  • Ensure observations are independent and the sample size is sufficiently larger than the number of predictors.
  • Continuous predictors should relate approximately linearly to the log odds; use transformations or alternative models if relationships are highly nonlinear.
  • Avoid strong multicollinearity among predictors; consider dimensionality reduction or removing correlated variables.
  • Choose the appropriate form: binary logistic regression for two categories and multinomial logistic regression for multiple categories.

實例

假設我們想預測某人是否會罹患心血管疾病 (1=有, 0=無)，自變數為年齡與是否吸菸。邏輯斯迴歸模型為 log(p/(1−p)) = β₀ + β₁·年齡 + β₂·吸菸，經估計後可得到各變數對罹病機率的影響。輸出機率 p=1/(1+e^{-(β₀+β₁·年齡+β₂·吸菸)})，若 p>0.5 可預測為罹患。

Suppose we want to predict whether someone has cardiovascular disease (1=yes, 0=no) based on their age and smoking status. A logistic model can be written as log(p/(1−p)) = β₀ + β₁ × age + β₂ × smoking. After fitting, the coefficients show how age and smoking influence the odds of disease. Converting to probability p = 1/(1 + e^{-(β₀ + β₁ × age + β₂ × smoking)}), we may classify someone as high risk if p > 0.5.

R 與 Python 範例

邏輯斯迴歸程式碼

下列程式示範如何在 R 和 Python 中產生邏輯斯曲線並擬合邏輯斯迴歸模型。

The following examples show how to generate a logistic curve and fit a logistic regression model in R and Python.


# 模擬數據並繪製 logistic 曲線
x <- seq(-5, 5, length.out = 100)
eta <- -1 + 0.8 * x
p <- 1 / (1 + exp(-eta))
plot(x, p, type="l", main="Logistic Function", xlab="x", ylab="p")

# 擬合邏輯斯迴歸模型
df <- data.frame(y = rbinom(100, 1, p), x = x)
model <- glm(y ~ x, data = df, family = binomial())
summary(model)
            

# simulate data and plot logistic curve
import numpy as np
import matplotlib.pyplot as plt
from sklearn.linear_model import LogisticRegression

x = np.linspace(-5, 5, 100)
eta = -1 + 0.8 * x
p = 1 / (1 + np.exp(-eta))
plt.plot(x, p)
plt.xlabel("x")
plt.ylabel("p")
plt.title("Logistic Function")
plt.show()

# fit logistic regression model
rng = np.random.default_rng(0)
y = rng.binomial(1, p)
X = x.reshape(-1, 1)
model = LogisticRegression()
model.fit(X, y)
print(model.intercept_, model.coef_)
