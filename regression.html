Step 8

線性回歸

線性回歸尋求兩個變數之間的最佳直線關係，計算斜率與截距並解釋模型決定係數。

Linear regression finds the best‑fitting linear relationship between two variables, computing the slope and intercept and interpreting the coefficient of determination.

概念

最小平方法

簡單線性回歸假定自變項 x 與因變項 y 之間呈線性關係 y=β₀+β₁x+ε。透過最小平方法選取斜率 β₁ 和截距 β₀，使預測值與觀察值的平方差總和最小。決定係數 R² 表示模型解釋總變異的比例。

The simple linear regression model assumes a linear relationship between the predictor x and response y: y=β₀+β₁x+ε. The least‑squares method chooses the slope β₁ and intercept β₀ to minimise the sum of squared deviations between predicted and observed values. The coefficient of determination R² indicates the proportion of total variation explained by the model.

Enter paired x,y data (one pair per line, separated by commas) to compute the regression slope, intercept and R², and plot the scatter with the fitted line.

優缺點與限制

線性迴歸的優勢與侷限

線性迴歸是最常見的統計模型之一，適合用來探索與預測連續變數之間的線性關係。其最大優點是易於計算與解釋，能提供斜率與截距幫助理解自變項與因變項之間的關係，也因為計算速度快而廣泛應用於各領域。

Linear regression is one of the most widely used statistical models for exploring and predicting relationships between continuous variables. Its main advantages are that it is simple to compute and interpret: the slope and intercept quantify how the predictor relates to the response, and the method runs quickly on both small and large datasets.

限制與注意事項

  • 模型假定自變項與因變項之間呈線性關係；對於彎曲或非線性關係，可能需要轉換變數或採用非線性模型。
  • 假設觀察值獨立且殘差具有相同變異（同質性）並呈常態分布；違反這些假設會影響斜率估計和 p 值的有效性。
  • 對離群值敏感，極端觀察可能對斜率造成不成比例的影響，需檢查並處理離群值。
  • 容易出現過度簡化或過度擬合；若使用多個解釋變量要注意共線性問題，並考慮正則化或交叉驗證。
  • 不應在資料範圍之外進行推論；線性迴歸只能在原有資料的範圍內進行預測，否則可能導致誤解。
  • Assumes a linear relationship between predictor and response; curved or non‑linear patterns require transforming variables or using non‑linear models.
  • Assumes independent observations with homoscedastic and normally distributed residuals; violating these assumptions affects slope estimates and p‑values.
  • Sensitive to outliers, which can disproportionately influence the estimated slope; examine and handle extreme observations carefully.
  • Can underfit complex relationships or overfit when including many predictors; be mindful of multicollinearity and consider regularisation or cross‑validation.
  • Do not extrapolate beyond the observed data range; linear regression is only valid within the range of the original data.
決策指引與範例

何時使用線性迴歸？

如果你的資料呈現近似直線關係，且每次觀測皆獨立且變異數穩定，線性迴歸是適合的工具。應避免在時間序列資料或非線性關係中直接套用；在這些情況下可先檢查散點圖與殘差圖，必要時採用變數轉換或其他模型。

Use linear regression when your data show an approximately straight‑line relationship and observations are independent with constant variance. Avoid applying it to time‑series data or strongly non‑linear relationships without transformations; instead inspect scatterplots and residual plots, and consider using variable transformations or alternative models if needed.

實例說明

例如我們想根據房屋面積預測房價。假設有以下數據：面積 50、60、80、100（平方公尺），對應的房價（百萬元）為 3、4、5、6.5。將這些數據套入線性迴歸，得到斜率約為 0.043，每增加一平方公尺，房價平均上升約 0.043 百萬元。決定係數 R² 約 0.98，表示面積可以解釋 98% 的價格變異。

For example, suppose we want to predict house price from floor area. Consider the following data: areas of 50, 60, 80, 100 square meters with corresponding prices (in millions) of 3, 4, 5, 6.5. Fitting a linear regression yields a slope of about 0.043, meaning each additional square meter adds roughly 0.043 million to the price. The coefficient of determination R² is approximately 0.98, indicating that area explains 98% of the variation in price.

程式範例

R 與 Python 範例

以下程式示範如何在 R 與 Python 中進行簡單線性迴歸，計算斜率、截距與 R²。您可以直接複製程式碼到 RStudio 或 Python 環境中運行。

The following examples show how to perform a simple linear regression in R and Python, computing the slope, intercept and R². You can copy these snippets into RStudio or a Python interpreter.

# 建立資料向量
x <- c(1, 2, 3, 4)
y <- c(2, 3, 5, 8)

# 擬合線性迴歸模型
model <- lm(y ~ x)

# 查看參數估計
summary(model)

# 取得斜率、截距與 R²
coef(model)[2]  # 斜率
coef(model)[1]  # 截距
summary(model)$r.squared  # R²
# -*- coding: utf-8 -*-
import numpy as np
from scipy import stats

# 定義自變項與因變項
x = np.array([1, 2, 3, 4])
y = np.array([2, 3, 5, 8])

# 使用 linregress 擬合迴歸線
slope, intercept, r, p, std_err = stats.linregress(x, y)

# 輸出斜率、截距與 R²
print(slope, intercept, r**2)
