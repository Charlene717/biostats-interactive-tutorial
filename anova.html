Step 7

變異數分析

用於比較三組以上樣本平均是否存在顯著差異的統計方法，透過 F 統計量比較組間與組內的變異大小。

A statistical method for testing whether three or more group means differ significantly. It uses the F statistic to compare variability between groups with variability within groups.

概念

一因子 ANOVA

ANOVA 將總變異拆分為組間變異與組內變異。若組間變異占比大，則不同組之均值可能不同。F 統計量 = (組間變異/自由度1) / (組內變異/自由度2)，自由度與組數及總樣本數相關。

ANOVA partitions the total variation into between‑group and within‑group components. If the between‑group variation is large relative to within‑group variation, the group means may differ. The F statistic is computed as (between‑group variation/df1) divided by (within‑group variation/df2), where the degrees of freedom depend on the number of groups and total sample size.

互動

比較多組均值

輸入至多三組資料（以逗號分隔），計算各組平均與 F 統計量。

Enter up to three groups of data (comma‑separated) to compute group means and the F statistic.

優缺點與限制

ANOVA 優勢與侷限

ANOVA 可以同時比較多個組別的平均數，避免逐一進行 t 檢定所造成的第一類錯誤累積效應；它還可以檢測因子之間的交互作用，具有較高的統計能力和靈活性。即使資料稍微偏離常態，ANOVA 通常仍能提供可靠結果。

ANOVA allows comparison of the means of three or more groups in one test, avoiding the Type I error inflation that occurs when performing multiple t‑tests. It can also test for interactions among factors, offers greater statistical power, and is flexible across different types of data. ANOVA is usually robust to moderate deviations from normality.

限制與注意事項

  • 假設資料來自常態分布且各組變異數相等；違反這些假設會導致結果不可靠。
  • 各觀察值須相互獨立，且樣本應隨機抽取，樣本數過小時 F 檢定可能不穩定。
  • ANOVA 只能告訴你是否存在顯著差異，無法指出哪些組別不同，也無法說明方向，必須搭配事後檢定。
  • 分析重點是平均數，對於分布偏態、變異數不等或極端值多的資料，可能需要改用 Welch’s ANOVA 或非參數檢定。
  • 進行多次比較會增加第一類錯誤風險，需採用適當的事後方法控制。
  • Assumes the data in each group are normally distributed with equal variances; violations can lead to inaccurate results.
  • Observations must be independent and drawn randomly. Small samples may make the F test unstable.
  • ANOVA only tells you whether a significant difference exists; it does not identify which groups differ or the direction of differences, so post‑hoc tests are required.
  • The test focuses on comparing means; when distributions are skewed, variances differ or there are outliers, consider using Welch’s ANOVA or a non‑parametric alternative.
  • Multiple comparisons increase the risk of Type I errors; appropriate post‑hoc procedures are needed to control error rates.
決策指引與範例

何時使用 ANOVA？

當你想比較三個或更多群組的平均數是否有差異時，應考慮使用 ANOVA。一因子 ANOVA 用於一個分類自變量，若有兩個以上因子則可採用二因子或多因子 ANOVA。使用前應檢查常態性與變異數同質性；若違反假設，考慮 Welch’s ANOVA 或非參數檢定（例如 Kruskal‑Wallis 檢定）。

Use one‑way ANOVA when you need to compare means across three or more groups defined by a single categorical factor. Two‑way or factorial ANOVA can evaluate multiple factors and their interactions. Before running ANOVA, verify that the data are roughly normal with similar variances; if assumptions are violated, consider Welch’s ANOVA or non‑parametric tests such as the Kruskal–Wallis test.

實例說明

假設我們想比較三種教學法對學生考試成績的影響：方法 A、B 與 C。隨機抽取各方法的學生，得到以下成績：5,6,7（方法 A），8,9,10（方法 B），7,7,8（方法 C）。ANOVA 的 F 檢定顯示組間變異大於組內變異，代表至少有一種教學法的平均成績不同。我們可以使用 post‑hoc 測試（如 Tukey HSD）找出差異在哪些組別。

Suppose we compare exam scores under three teaching methods (A, B and C) with samples: 5,6,7 for A, 8,9,10 for B and 7,7,8 for C. A one‑way ANOVA yields an F statistic where the between‑group variability exceeds the within‑group variability, indicating at least one mean differs. Post‑hoc tests (e.g. Tukey’s HSD) can then identify which methods differ.

程式範例

R 與 Python 範例

以下程式示範如何在 R 與 Python 中進行單因子 ANOVA。您可以直接複製程式碼到 RStudio 或 Python 環境中運行，得到 F 統計量與 p 值。

The following examples demonstrate how to perform a one‑way ANOVA in R and Python. You can paste these snippets into RStudio or a Python interpreter to obtain the F statistic and p‑value.

# 建立三組數據
g1 <- c(5, 6, 7)
g2 <- c(8, 9, 10)
g3 <- c(7, 7, 8)

# 形成因子與值向量
groups <- factor(rep(c(\"G1\", \"G2\", \"G3\"), c(3, 3, 3)))
values <- c(g1, g2, g3)

# 執行單因子 ANOVA 並列印摘要
model <- aov(values ~ groups)
summary(model)
# -*- coding: utf-8 -*-
import scipy.stats as stats

# 三個樣本群組
g1 = [5, 6, 7]
g2 = [8, 9, 10]
g3 = [7, 7, 8]

# 執行單因子 ANOVA
f_stat, p_val = stats.f_oneway(g1, g2, g3)
print(f_stat, p_val)
