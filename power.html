Step 11

檢定力與樣本數

研究設計必須考慮檢定力：足夠的樣本數可降低犯第二型錯誤的機率。

Study design must consider statistical power: having enough participants reduces the probability of making a type II error.

概念

檢定力

檢定力 (power) 為 1−β，表示在真實存在效應時拒絕零假設的機率。檢定力太低會增加第二型錯誤（漏檢）的風險。規劃研究時需決定可接受的 α 與 β，以及預期效果大小與變異，據此計算所需樣本數。

Statistical power is defined as 1−β, the probability of rejecting the null hypothesis when a true effect exists. Low power increases the risk of a type II error (failing to detect a real effect). When planning a study one must set acceptable α and β and specify the expected effect size and variability to compute the required sample size.

互動

計算樣本數

假設欲比較兩組平均，輸入預期的效果大小 Δ、標準差 σ、顯著水準 α 以及期望檢定力 (1−β)。計算公式 n = 2·((z1−α/2 + z1−β)·σ/Δ)2。結果為每組所需樣本數。

For comparing two means, enter the expected effect size Δ, the standard deviation σ, the significance level α and the desired power (1−β). The required sample size per group is n = 2·((z1−α/2 + z1−β)·σ/Δ)2.

優缺點與限制

檢定力與樣本數的優點

在研究設計階段進行檢定力分析能夠估算所需樣本數，避免樣本過少而偵測不到真實效應，或樣本過多造成資源浪費與倫理問題。計畫合理的樣本數有助於提升研究效率、確保結論具說服力，並常被要求於研究計畫書中。

Performing a power analysis during study planning helps you determine how many participants you need so your study is neither under‑powered (risking missed effects) nor excessively large (wasting resources or raising ethical concerns). Determining an appropriate sample size improves study efficiency, ensures convincing results and is often required in grant proposals.

缺點與限制

檢定力分析依賴於事先假設，例如預期效果大小與標準差，因此計算結果通常只是最佳情況估計。當研究方法或統計模型改變時需重新計算樣本數，而且複雜模型可能需要比計算結果更大的樣本。此外，檢定力並非唯一考量，研究者還需顧及研究設計、估計精準度及統計假設是否適用。

Power analyses rely on assumptions such as anticipated effect size and variability, so the results are only “best‑case” estimates. Changing the study design or statistical model often requires recalculating the sample size, and some complex analyses demand larger samples than standard formulas suggest. Power is not the only consideration: researchers must also consider precision, model assumptions and overall study design.

決策指引與範例

如何使用檢定力分析

決定樣本數時，需同時考量預期效果大小、標準差、顯著水準 α 及期望的檢定力 (1−β)。若研究較重視偵測差異，可以選擇較高的檢定力，例如 0.9；若資源有限，可透過提高預期效果大小或降低顯著水準來減少樣本需求，但需考慮型 I/II 錯誤平衡。

To determine an appropriate sample size, specify the expected effect size, standard deviation, significance level α and desired power (1−β). If detecting a difference is critical, you might choose higher power (e.g., 0.9). If resources are limited you could assume a larger effect or use a less stringent α to reduce the sample size, but this changes the balance between type I and type II errors.

實際範例

假設想比較兩種治療的平均差異 Δ = 2，標準差 σ = 3，希望以 α = 0.05、檢定力 0.8 進行雙尾 t‑檢定。將這些數值代入公式 n = 2·((z1−α/2 + z1−β)·σ/Δ)2 可得每組所需樣本數。以這些設定為例，大約需要 36 名受試者。本頁的互動工具可協助您試算不同參數下的樣本數。

Suppose you wish to compare two treatments with an expected mean difference Δ = 2 and standard deviation σ = 3 using a two‑sided test with α = 0.05 and desired power 0.8. Plugging these values into the formula n = 2·((z1−α/2 + z1−β)·σ/Δ)2 gives the required sample size per group. For these numbers the result is about 36 participants per group. R 與 Python 範例

檢定力計算示範


# 使用 pwr 套件進行雙樣本 t 檢定檢定力分析
library(pwr)
# 預期差異與標準差
delta <- 2
sigma <- 3
# 轉換為效應大小 d
effect_size <- delta / sigma
# 進行功效分析（雙尾）
pwr_result <- pwr.t.test(d = effect_size,
                     power = 0.8,
                     sig.level = 0.05,
                     type = "two.sample",
                     alternative = "two.sided")
# 所需每組樣本數
required_n <- ceiling(pwr_result$n)
print(pwr_result)


# Power analysis for two-sample t test using statsmodels
import numpy as np
from statsmodels.stats.power import TTestIndPower

# expected difference and standard deviation
delta = 2
sigma = 3
effect_size = delta / sigma

# solve for required sample size per group
analysis = TTestIndPower()
result = analysis.solve_power(effect_size=effect_size,
                               power=0.8,
                               alpha=0.05,
                               alternative='two-sided')
required_n = int(np.ceil(result))
print(required_n)
