t 檢定與信賴區間

介紹 t 分布及其在均值檢定和信賴區間估計中的應用，並提供動手計算。

Learn about the t distribution and its use in mean testing and confidence interval estimation with an interactive calculator.

概念

t 分布與條件

當母體標準差未知且樣本數較小時，採用 t 分布進行均值檢定。t 分布依賴自由度，樣本量越大，其形狀越接近標準常態分布。假設檢定的基本步驟包括建立假設、選擇顯著水準、計算 t 統計量、查臨界值並做出結論。

When the population standard deviation is unknown and the sample size is small, the t distribution is used for mean testing. The shape of the t distribution depends on the degrees of freedom and approaches the standard normal distribution as the sample size grows. Hypothesis testing steps include formulating hypotheses, choosing the significance level, computing the t statistic, checking the critical value and drawing conclusions.

信賴區間

信賴區間提供參數可能值的範圍。例如對母體均值 μ 的 (1−α)100% 信賴區間為 x̄ ± z1−α/2·s/√n，其中 z 臨界值取自標準常態分布。當 n 較小或要求精確時，可使用 t 臨界值。

A confidence interval gives a range of plausible values for a parameter. For example, a (1−α)100% confidence interval for the population mean μ is x̄ ± z1−α/2·s/√n, where the z critical value comes from the standard normal distribution. When n is small or precision is important, one should use t critical values.

優缺點與限制

t 檢定與信賴區間的利弊

t 檢定的優點包括可以在樣本數較小或母體標準差未知的情況下比較平均值，計算方式簡單且廣泛應用於科學與實務領域。適度偏離常態分布時仍具有一定的穩健性，尤其是樣本規模相同時。其缺點是必須假設資料近似常態並且兩組變異相等；當資料極度偏斜或變異不等、樣本獨立性或隨機性不足時，t 檢定可能產生偏差或功效不足。信賴區間的優點是提供參數可能值的範圍，比單一 p 值更能顯示估計的不確定性；區間越窄表示估計越精確。缺點是易被誤解為參數落在區間內的機率，並且寬度受樣本大小與變異影響，樣本數不足或假設不符時區間可能過寬或偏差。

Advantages of t‑tests include their ability to compare means when the sample size is small and the population standard deviation is unknown. They are easy to compute and widely used across scientific and applied fields. T‑tests are reasonably robust to moderate deviations from normality, particularly when group sizes are similar. Limitations include assumptions of approximate normality and equal variances; if the data are highly skewed, have unequal variances, or the observations are not independent, the t‑test can be biased or under‑powered. Confidence intervals offer a range of plausible values for a parameter and convey uncertainty more clearly than a single p‑value; narrower intervals imply more precise estimates. However, they are often misinterpreted as giving the probability that the parameter lies inside the interval, and their width depends on sample size and variability—small samples or violated assumptions lead to wide or biased intervals.

決策指引與範例

如何選用 t 檢定與信賴區間

在實務上使用 t 檢定時，首先考慮比較的對象及假設。例如想知道某班學生的平均睡眠時數是否不同於推薦的 8 小時，可採用單樣本 t 檢定；比較兩獨立班級的平均成績則使用兩樣本 t 檢定；前後測相同受試者的分數差異可選擇配對 t 檢定。在進行檢定前應確認樣本為隨機且觀察值獨立，檢視數據是否近似常態並評估兩組變異是否相近。建議設定顯著水準（如 0.05），並根據研究問題決定單尾或雙尾檢定。計算信賴區間時，依樣本大小及是否知道母體標準差選擇 z 或 t 臨界值：小樣本且未知標準差時應使用 t 臨界值。範例：假設收集 15 名受試者每天睡眠時數的樣本均值為 7.3 小時、標準差為 0.8 小時，若計算 95% 信賴區間 [7.0, 7.6]，區間不包含 8 小時，表示其平均睡眠時間顯著少於建議值。

When applying t‑tests in practice, begin by identifying the comparison and hypothesis. A one‑sample t‑test checks whether the mean of a single sample differs from a reference value (e.g., are students in a class sleeping different from the recommended 8 hours?). A two‑sample t‑test compares the means of two independent groups (e.g., exam scores of two classes), while a paired t‑test compares measurements from the same subjects at two time points (e.g., before and after an intervention). Before testing, ensure your sample is random and observations are independent; examine whether the data are roughly symmetric and whether group variances are similar. Choose a significance level (commonly 0.05) and determine whether a one‑ or two‑tailed test matches your question. For confidence intervals, select a z or t critical value depending on sample size and whether the population standard deviation is known—use t critical values for small samples with unknown σ. For example, if 15 subjects have an average sleep time of 7.3 hours with a standard deviation of 0.8 hours, a 95% CI of [7.0, 7.6] does not include 8, indicating the group sleeps significantly less than the recommendation.

程式範例

使用 R 與 Python 計算 t 檢定與信賴區間

下面的程式碼示範如何在 R 和 Python 中執行單樣本 t 檢定並計算平均值的信賴區間。你可以切換標籤查看不同語言，並點擊複製按鈕取得代碼。

The following examples show how to perform a one‑sample t‑test and compute a confidence interval for the mean in R and Python. Use the tabs to switch languages and click the copy button to grab the code.

# 建立範例資料向量
data <- c(7.1, 8.3, 6.8, 7.5, 8.0)

# 單樣本 t 檢定：檢驗平均值是否等於 7.5
  t.test(data, mu = 7.5, conf.level = 0.95)

# 手動計算信賴區間
  xbar <- mean(data)
  s <- sd(data)
  n <- length(data)
  alpha <- 0.05
  t_crit <- qt(1 - alpha/2, df = n - 1)
  margin <- t_crit * s / sqrt(n)
  ci <- c(xbar - margin, xbar + margin)
  ci
# Import required packages
import numpy as np
from scipy import stats

# Example data array
data = np.array([7.1, 8.3, 6.8, 7.5, 8.0])

# One‑sample t‑test against 7.5
  t_stat, p_val = stats.ttest_1samp(data, popmean = 7.5)

# Compute the confidence interval
  n = len(data)
  xbar = np.mean(data)
  s = np.std(data, ddof = 1)
  alpha = 0.05
  t_crit = stats.t.ppf(1 - alpha/2, df = n - 1)
  margin = t_crit * s / np.sqrt(n)
  ci = (xbar - margin, xbar + margin)
  ci
