機率分布

認識常見的分布，如常態分布與二項分布，並透過圖像探索其形狀、平均與變異。

Learn about common distributions such as the normal and binomial distributions and explore their shapes, means and variances through interactive plots.

概念

常態分布

常態分布是連續、鐘形且對稱的分布，其位置由平均值 μ 決定，寬度由標準差 σ 決定。其機率密度函數為 f(x) = (1/(σ√(2π)))·exp(−(x−μ)²/(2σ²))，稱為高斯曲線，滿足總面積為 1。經驗法則指出資料若近似常態分布，約 68% 落在 μ±σ，95% 落在 μ±2σ。

The normal distribution is a continuous, bell‑shaped and symmetric distribution whose location is determined by the mean μ and whose width is determined by the standard deviation σ. Its probability density function f(x) = (1/(σ√(2π)))·exp(−(x−μ)²/(2σ²)) describes the well‑known Gaussian curve, with total area equal to 1. The empirical rule says that about 68% of values lie within μ±σ and 95% within μ±2σ.

二項分布

二項分布描述有限次獨立重複試驗中成功次數的機率，試驗次數為 n，每次成功機率為 p。若 X∼Bin(n,p)，其期望值為 np、變異數為 np(1−p)。當 n 較大且 p 不太接近 0 或 1 時，二項分布的形狀近似常態。

The binomial distribution models the probability of a fixed number of successes in n independent and identical trials, each with success probability p. If X∼Bin(n,p), its expected value is np and its variance is np(1−p). When n is large and p is not near 0 or 1, the binomial distribution becomes approximately normal.

優缺點與限制

常態分布

優點：常態分布可以描述許多自然與人為過程，計算只需平均數與標準差，並有現成的表與函數方便查表；在樣本量足夠且資料近似連續時，它能提供良好的近似。缺點與限制：實際資料不一定完美遵循常態分布，偏態、重尾或離群值會影響平均與標準差的解釋；若資料量太小或不是連續型資料，需要先檢查常態性，必要時考慮其他分布或轉換。適用條件：樣本量足夠大、資料為連續型，且檢驗顯示近似常態時，可使用常態分布作為模型基礎。

Advantages: The normal distribution can describe many natural and manufactured processes, calculations rely only on the mean and standard deviation, and there are tables and built‑in functions for quick lookup; with sufficient data and nearly continuous observations it provides a good approximation. Drawbacks & limitations: Real‑world data rarely follow a perfect bell curve; skewness, heavy tails or outliers can distort the mean and standard deviation. When sample sizes are small or the data are not continuous, you should test for normality and consider alternative distributions. Applicable conditions: Use the normal model when you have a sufficiently large sample, continuous data and tests indicate the distribution is approximately normal.

二項分布

優點：二項分布適用於有固定次數且每次只有成功或失敗兩種結果的試驗，例如投擲硬幣、回答是非題或臨床試驗。它的機率計算簡單，期望值為 np、變異數為 np(1−p)，並且在 n 較大且 p 不太接近 0 或 1 時可以用常態近似。缺點與限制：僅能處理二分類結果，假設每次試驗獨立且成功機率固定；若試驗之間存在依賴或概率隨時間改變，則不適用。此外當成功機率極端時，分布會高度偏斜，難以使用常態近似。適用條件：有固定次數 n、每次只有兩種結果，且試驗獨立並在相同條件下重複時，可使用二項分布模型。

Advantages: The binomial distribution applies to experiments with a fixed number of trials and only two outcomes on each trial (success or failure). It is widely used for modelling counts of successes in coin flips, multiple‑choice questions and clinical studies; probabilities are easy to compute and the mean and variance are simple functions of n and p. When n is large and p is not near 0 or 1, the binomial can be approximated by a normal curve. Drawbacks & limitations: It only handles binary outcomes and assumes each trial is independent and the success probability remains constant. If trials influence each other or probabilities change over time, the binomial model is invalid. When p is very low or very high the distribution is heavily skewed and the normal approximation fails. Applicable conditions: Use the binomial model when there is a fixed number of independent trials conducted under identical conditions, with the probability of success p the same on each trial.

決策引導與範例

判斷應使用哪種分布時，可先確認資料類型和試驗設計。例如，若研究學生期末考成績，分數可取連續值且由許多小影響累積而成，常以常態分布近似；若研究投擲 10 次硬幣出現正面次數，此為固定次數的二元事件，適合用二項分布。實務上，若成功機率固定且試驗獨立，可選擇二項分布；反之，若變量為連續且受眾多隨機因素影響，則考慮常態分布。

When deciding which distribution to use, start by identifying the data type and experiment design. Exam scores, which take on continuous values and result from many small influences, are often approximated by a normal distribution. The number of heads in ten coin flips is a fixed number of binary trials, so the binomial distribution is appropriate. In general, choose a binomial model when you have independent trials with a constant probability of success; choose a normal model for continuous measurements shaped by many random influences.

程式範例

下方提供 R 與 Python 程式碼示範，展示如何產生常態密度函數與二項分布機率質量函數，並繪製對應圖形。點擊複製按鈕即可複製程式碼。

Below are R and Python code examples showing how to generate the normal density and binomial probability mass functions and plot them. Click the copy icon to copy the code.

# 計算並繪製常態密度與二項機率質量函數
x <- seq(-4, 4, length.out = 100)
# 常態分布密度 (均值 0，標準差 1)
y_norm <- dnorm(x, mean = 0, sd = 1)
# 二項分布機率 (n = 10, p = 0.5)
k <- 0:10
y_binom <- dbinom(k, size = 10, prob = 0.5)
print(y_binom)
# 繪製常態密度曲線
plot(x, y_norm, type = 'l', main = 'Normal PDF', xlab = 'x', ylab = 'Density')
# 繪製二項分布柱狀圖
barplot(y_binom, names.arg = k, main = 'Binomial PMF', xlab = 'k', ylab = 'P(X = k)')
# compute and plot normal density and binomial PMF
import numpy as np
from scipy.stats import norm, binom
import matplotlib.pyplot as plt
# Normal PDF (mean=0, sd=1)
x = np.linspace(-4, 4, 100)
y_norm = norm.pdf(x, loc=0, scale=1)
# Binomial PMF (n=10, p=0.5)
k = np.arange(0, 11)
y_binom = binom.pmf(k, n=10, p=0.5)
print(y_binom)
# Plot normal density
plt.plot(x, y_norm)
plt.xlabel('x'); plt.ylabel('Density'); plt.title('Normal PDF')
plt.show()
# Plot binomial PMF
plt.bar(k, y_binom)
plt.xlabel('k'); plt.ylabel('P(X=k)'); plt.title('Binomial PMF')
plt.show()
